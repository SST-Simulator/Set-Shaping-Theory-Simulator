Set Shaping Theory can be applied to many research fields and has significant potential. To make the simulations as meaningful as possible, we need experts in the relevant research fields who can help define the most relevant problems, methods, metrics, and practical interpretations.

What we are observing is that larger but more structured inputs can improve performance. In other words, input structure is more critical than input size.

The general research methodology is as follows:

  1. Select a problem and its most widely used solution method.
  2. Define a metric or function to measure the method's performance.
  3. Apply SST to evaluate whether this performance improves on average.
  4. Consult experts in the relevant research fields to determine whether the improvement is practically significant.

If SST provides an improvement, it can be applied directly to the input without changing the underlying method itself. Set Shaping Theory is not in competition with existing theories or algorithms: it aims to improve results by producing more structured inputs.

As computers become increasingly powerful, the calculations required for this approach will become more accessible, making this type of application progressively more widespread.

In the future, the resolution of problems will use only expanded and more structured inputs.

Why \(N H_0(s)\) is important

The size of the coded message, using a uniquely decipherable code, is given by the product of the message length \(N\), measured as the number of symbols, and the zero-order empirical entropy \(H_0(s)\).

\[L(s)=N H_0(s)\]

\[(N+K)H_0(f(s))-N H_0(s)\]

Why \(N H_0(s)+R_{KT}(s)\) is important

The size of the coded message, using a uniquely decipherable code, is given by the product of the message length \(N\), measured as the number of symbols, and the zero-order empirical entropy \(H_0(s)\), computed from the empirical symbol frequencies inside the sequence.

The Krichevsky-Trofimov redundancy \(R_{KT}\) measures the bit cost due to not knowing the true probability distribution of a source.

Let \(s\) be a sequence of length \(n\) over an alphabet of size \(A\), and let \(n_i\) be the number of occurrences of symbol \(i\).

\[ R_{KT}(s)= -\log_2\!\left[ \frac{\Gamma\!\left(\frac{A}{2}\right)} {\pi^{A/2}\Gamma\!\left(n+\frac{A}{2}\right)} \prod_{i=1}^{A}\Gamma\!\left(n_i+\frac{1}{2}\right) \right]-nH_0(s) \]

Therefore, the encoding limit of the universal KT model is:

\[ L_{KT}(s)=nH_0(s)+R_{KT}(s) \]

In the simulations this limit is an insurmountable value for universal encoders: they approach it closely but do not exceed it.

Example with \(A=10\) and \(N=110\)
\(N H_0(s)+R_{KT}(s)=L_{KT}(s)\) 347.538812
Adaptive arithmetic 347.538812
Adaptive ANS 347.547108
Adaptive arithmetic + SST 345.948954
Adaptive ANS + SST 345.956542

Set Shaping Theory overcomes this limitation by applying the transformation before the universal encoder.

This is an important result for the following reasons

  1. It reduces an inefficiency that was thought to be impossible to overcome, experimentally showing that an equivalent but more structured representation of the sequence exists.
  2. The gain occurs for five universal encoders that operate in completely different ways. The transformed sequence is the same for every encoder, showing that it is truly more structured.

Important

This does not mean that a random sequence can be compressed. The result is the reduction of an inefficiency that was considered insurmountable.

Why Degree entropy, Adjacency-gap entropy and Similarity are important

Degree entropy

Degree entropy is important because it measures how heterogeneous the connectivity of a graph is. A low degree entropy means that many nodes have similar degrees, indicating a more regular and structured graph. From a practical point of view, this matters because regular graphs are often easier to store, compress, analyze, and process computationally. It can also help identify whether a transformation makes the graph simpler without changing its essential connectivity.

Adjacency-gap entropy

Adjacency-gap entropy is important because it captures how ordered or clustered the connections are inside the adjacency representation. If the gaps between connected nodes are repetitive or regular, the graph is easier to describe and compress. Practically, this parameter is useful because many graph algorithms depend on memory access patterns and adjacency-list organization. Lower adjacency-gap entropy can indicate better locality, faster traversal, and more efficient storage.

Similarity

Similarity measures the average structural overlap between node neighborhoods inside a graph, using the mean Jaccard similarity between all pairs of nodes. A higher value indicates that nodes share more common neighbors and that the graph has more regular local connectivity patterns. This is useful for graph compression, community detection, network simplification, and anomaly detection, because repeated or coherent neighborhood structures are easier to store, analyze, and compare after transformation.

Why the structural parameters Collisions/record and Max cluster are important

These parameters are related to the number of accesses to the RAM and the percentage of RAM that must be left free.

A set of \(N\) elements associated with a hash function can produce collisions. This means that two or more elements may correspond to the same hash value. This creates two practical problems:

1) More RAM accesses are needed, and RAM accesses are slow.

2) The table cannot use all available RAM. A free memory margin, often between 5% and 40%, must be kept to reduce long probe chains. Since RAM is one of the most expensive components, unused memory can become a significant cost.

After the Set Shaping Theory transformation, the new elements are slightly longer but more structured. This structure helps the hash function assign the elements more uniformly and reduce collisions as much as possible.

Therefore, we spend a little more CPU time to compute the transformation and its inverse, but we can use RAM more efficiently, even close to 95%, while reducing slow RAM accesses.

In this way, the data are structured so that part of the workload is moved from expensive RAM access to powerful and cheaper CPU computation.

Collisions/record: This measures how often stored records compete for the same placement region.

Max cluster: This captures the largest contiguous occupied region, which is directly related to long RAM probe chains.

Expert feedback

The main practical advantage of this technique is that it can be applied without changing the hardware or the underlying database infrastructure. In real production systems, memory layout, cache behavior, probing strategies, and hash-table implementations are already highly optimized, so even small architectural changes can be expensive, risky, and difficult to deploy.

Set Shaping Theory acts at the input-representation level. It makes the data more structured before they are processed by the existing system, allowing performance improvements without redesigning the hardware, replacing the storage engine, or modifying the core lookup method. This compatibility with existing optimized systems may be one of its most important advantages.

We thank the experts who provided this feedback and helped clarify the practical relevance of the method in real database systems.

Why Kullback-Leibler divergence is important

Kullback-Leibler divergence

Kullback-Leibler divergence is important because it measures how much one probability distribution differs from another. In this application, it compares the histogram of the original image with the histogram of the image after message embedding. A lower Kullback-Leibler divergence value means that the modified image remains statistically closer to the original image.

From a practical point of view, this method does not replace standard steganographic techniques. Instead, it acts as a preprocessing step that reshapes the message before embedding. In this way, any chosen steganographic method can be applied more effectively, because the message representation is selected to produce a smaller statistical distortion in the carrier image and therefore a better embedding result.
